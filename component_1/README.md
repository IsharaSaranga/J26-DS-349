# Component 1 – HGSS-ABSA

## Project

Smart Phone & Laptop Comparison Assistant Using Aspect Level Insights from User Reviews

**Project ID:** J26-DS-349

## Component Title

Uncertainty-Aware Hierarchy-Guided Cross-Category Aspect-Based Sentiment Analysis for Smartphone and Laptop Reviews

## Research Contribution

This component investigates whether an explicit semantic hierarchy consisting of:

- Common aspects
- Phone-specific aspects
- Laptop-specific aspects

can guide selective knowledge transfer between smartphone and laptop review domains while preserving category-specific knowledge.

## Planned Models

- B1 – Separate-Domain Models
- B2 – Flat Pooled Cross-Category Model
- B3 – Generic Shared/Private Model
- B4 – Proposed HGSS-ABSA Model

## Planned Output

Aspect – Semantic Group – Sentiment – Confidence

Environment setup and dataset inspection.
